Bibliotecas fundamentales

Python se ha convertido en uno de los lenguajes más utilizados para implementar métodos numéricos, gracias a su sintaxis clara, su carácter de código abierto y sus bibliotecas especializadas en cálculo científico.

BibliotecaUso principal
NumPyManejo eficiente de arreglos y matrices, y funciones de álgebra lineal.
SciPyImplementaciones optimizadas de métodos numéricos (raíces, integración, EDO, optimización).
MatplotlibGeneración de gráficos para visualizar funciones, errores y resultados.
PandasOrganización y análisis de datos tabulares, útil para resultados de iteraciones.

Ejemplo: épsilon y error de redondeo

Este fragmento ilustra el épsilon de la máquina y un caso típico de error de redondeo:

import numpy as np

# Épsilon de la máquina en precisión doble
eps = np.finfo(float).eps
print('Épsilon de la máquina:', eps)

# Ejemplo de error de redondeo
a = 0.1 + 0.2
print('0.1 + 0.2 =', a)
print('¿Es igual a 0.3? ->', a == 0.3)

La suma 0.1 + 0.2 no produce exactamente 0.3 debido a la representación binaria en punto flotante, tal como se explicó en el tema de aritmética de punto flotante.

Ejemplo: error absoluto y relativo

def error_absoluto(x_real, x_aprox):
    return abs(x_real - x_aprox)

def error_relativo(x_real, x_aprox):
    return abs(x_real - x_aprox) / abs(x_real)

x_real = 3.14159265
x_aprox = 3.1416

print('Error absoluto:', error_absoluto(x_real, x_aprox))
print('Error relativo:', error_relativo(x_real, x_aprox))
