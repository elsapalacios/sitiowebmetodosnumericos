Tema 04 — Teoría de errores

Errores de redondeo y aritmética de computadores

Error inherente, de truncamiento y de redondeo; error absoluto y relativo.

En esta página

  1. Tipos de error
  2. Error absoluto y relativo
  3. Propagación del error

Tipos de error

  1. Error inherente: proviene de la imprecisión de los datos de entrada, ya sea por mediciones experimentales o por representaciones aproximadas de constantes.
  2. Error de truncamiento: se produce al reemplazar un proceso infinito —una serie, una derivada, una integral— por una aproximación finita, como al truncar una serie de Taylor.
  3. Error de redondeo: surge porque el computador solo puede almacenar un número finito de cifras significativas, obligando a redondear resultados intermedios y finales.

Error absoluto y error relativo

Dado un valor aproximado (xa) y un valor real (xr), se definen:

Error absoluto  Ea = | x_r − x_a |
Error relativo   Er = | x_r − x_a | / | x_r |

El error absoluto indica la magnitud de la diferencia entre el valor real y el aproximado, mientras que el error relativo la expresa en proporción al valor real — más útil para comparar precisión entre cantidades de distinta magnitud.

Propagación del error

Cuando se realizan operaciones encadenadas, los errores de redondeo de cada paso pueden acumularse a lo largo del cálculo. Un algoritmo se considera numéricamente estable cuando esta propagación se mantiene acotada, e inestable cuando pequeños errores iniciales se amplifican de forma descontrolada a medida que avanza el cálculo.
